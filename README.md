# Contact Management API

## About

This is a Contact Management API challenge.

Everyone will build their own complete implementation of the API. The goal is to work on the same problem independently and later compare the different approaches and solutions.

## How to Participate

### 1. Fork the Repository

If you are new to GitHub, **forking** means creating your own copy of this repository under your GitHub account.

On the original GitHub repository:

1. Click the **Fork** button at the top right.
2. Select your GitHub account.
3. GitHub will create a copy of the repository in your account.

For example:

**Original repository:**

```text
github.com/original-account/contact-api
```

**Your fork:**

```text
github.com/your-username/contact-api
```

Make sure you work from **your fork**, not the original repository.

### 2. Clone Your Fork

Open your fork on GitHub and click **Code**.

Copy the HTTPS URL, then open your terminal and run:

```bash
git clone YOUR_FORK_URL
```

For example:

```bash
git clone https://github.com/your-username/contact-api.git
```

Move into the project folder:

```bash
cd contact-api
```

### 3. Create Your Branch

Don't work directly on the `main` branch.

Create a new branch for your implementation:

```bash
git checkout -b feature/contact-api
```

You can check the branch you are currently on with:

```bash
git branch
```

### 4. Build the API

The Contact Management API should have the following features:

* Add a contact
* Update a contact
* Delete a contact
* Get a particular contact
* Search contacts
* Add tags such as family, friend, work, etc.
* Favorite a contact

You are free to decide how you want to structure and implement the API.

The important thing is that everyone builds the complete API independently.

## 5. Commit Your Changes

Once you have completed your implementation, add your changes:

```bash
git add .
```

Commit your changes:

```bash
git commit -m "feat: implement contact management API"
```

## 6. Push Your Branch

Push your branch to your GitHub fork:

```bash
git push -u origin feature/contact-api
```

After this, your branch and your changes should be available on your GitHub fork.

## 7. Create a Pull Request

Go to your GitHub fork.

GitHub should show an option to create a **Pull Request** for the branch you just pushed.

Your Pull Request should be:

```text
Your fork → Original repository
```

A Pull Request means that you are asking for your completed work to be reviewed and considered for the original repository.

**Do not merge your Pull Request yourself.**

The submissions will be reviewed so we can look at the different implementations and approaches.

## GitHub Flow

If you are new to GitHub, the process is simply:

```text
Original Repository
        ↓
      Fork
        ↓
      Clone
        ↓
 Create Branch
        ↓
   Build API
        ↓
     Commit
        ↓
      Push
        ↓
 Pull Request
```

## Challenge Purpose

Participation is completely optional.

The purpose of this challenge is to give everyone an opportunity to practice, build something independently, and learn from the different approaches taken by others.

We are all solving the same problem, but everyone gets to decide how they want to structure and implement their solution.
